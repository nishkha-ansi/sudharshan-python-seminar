02 · Programming paradigm

Automata-based programming

An automaton is a mathematical model of computation. A finite automaton reads an input string symbol by symbol and changes its state using transition rules. The unit introduces DFA and NFA.

DFA

Deterministic Finite Automaton: for each state and input symbol, exactly one next state is defined.

NFA

Nondeterministic Finite Automaton: a state and input symbol may lead to more than one possible next state.

Basic terms

Alphabet: finite set of symbols. String: sequence of symbols. Language: set of strings over an alphabet.

04 · Programming paradigm

Event-driven programming

In event-driven programming, the flow of a program is determined by events such as mouse clicks, key presses or other user interactions.

Event

An action or occurrence recognised by a program, such as a button click.

Event handler

A function or method that performs an action when an event occurs.

Event loop

Waits for events and dispatches them to the appropriate event handlers.

Tkinter library

Tkinter is Python's standard GUI library. A typical Tkinter program creates a root window, adds widgets such as buttons and starts the event loop using mainloop().

05 · Separate code examples

Sample Python codes

These examples are kept separate from the paradigm explanations. The first uses plain Python, the second uses SymPy, and the third uses Tkinter.

Sample 1 — DFA: binary string ending in 1

Python code
def accepts_ending_in_1(text):
    state = "q0"

    for symbol in text:
        if symbol == "1":
            state = "q1"
        elif symbol == "0":
            state = "q0"
        else:
            return False

    return state == "q1"

print(accepts_ending_in_1("101"))  # True
print(accepts_ending_in_1("100"))  # False

Sample 2 — Symbolic mathematics using SymPy

Python code
import sympy as sp

x = sp.symbols('x')
expr = (x + 2)**2

print("Expanded:", sp.expand(expr))
print("Derivative:", sp.diff(expr, x))
print("Integral:", sp.integrate(expr, x))
print("Solve:", sp.solve(expr - 9, x))
Click “Run Sample 2” to see the output.

This example requires the SymPy library when run in a Python environment.

Sample 3 — Event-driven GUI using Tkinter

Python code
import tkinter as tk
from tkinter import messagebox

def say_hello():
    messagebox.showinfo(
        "Python Event Demo",
        "Button clicked!"
    )

root = tk.Tk()
root.title("Event Demo")

button = tk.Button(
    root,
    text="Click Me",
    command=say_hello
)
button.pack(padx=20, pady=20)

root.mainloop()
Click “Run Sample 3” to see the output.

06 · Practical project

EduAI — AI-powered learning assistant

EduAI is a proposed educational assistant that helps students organise learning, practise topics and review their understanding. This project section demonstrates how a Python project can be planned and developed. The current webpage contains a working front-end prototype; it does not connect to a real AI model or store student data.

📘

Topic learning

Students select a topic and view a short learning prompt or revision summary.

📝

Practice quiz

Students answer quick questions and receive immediate feedback.

📈

Progress feedback

The prototype displays the quiz score and suggests whether to revise or continue.

Project objectives

  • Provide a simple interface for learning support.
  • Help students practise with topic-based questions.
  • Give instant feedback on answers.
  • Demonstrate a structured software project.

Development methodology

  1. Identify the learning-support problem.
  2. Design topic, quiz and result modules.
  3. Implement the interface and quiz logic.
